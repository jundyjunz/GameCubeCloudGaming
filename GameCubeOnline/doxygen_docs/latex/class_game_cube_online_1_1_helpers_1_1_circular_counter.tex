\doxysubsection{Detailed Description}
\doxylink{class_game_cube_online_1_1_helpers_1_1_circular_counter}{Circular\+Counter}. 

A counter that loops around itself at a specified value. It can be implicitly converted to int if need be. ~\newline
 You can also set a value to have it start counting at, but it is by default 0.
