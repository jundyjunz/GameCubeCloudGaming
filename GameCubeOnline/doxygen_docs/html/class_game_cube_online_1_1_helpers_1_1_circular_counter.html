Detailed Description

CircularCounter.

A counter that loops around itself at a specified value. It can be implicitly converted to int if need be.
You can also set a value to have it start counting at, but it is by default 0.

Example Usage:

avr theCounter CircularCounter(10, 9);
theCounter++;
int theNum = theCounter // theNum=0; 10%10 = 0.
